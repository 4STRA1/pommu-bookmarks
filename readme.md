Pommu bookmarks

DLsiteの「pommu」で投稿をブックマークし、タグを付けて整理・検索できるようにするTampermonkeyユーザースクリプトです。

対応サイト

https://ch.dlsite.com/pommu/

インストール

Tampermonkey必須。

↓Google Chrome版↓
https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo?hl=ja

↓Firefox版↓
https://addons.mozilla.org/ja/firefox/addon/tampermonkey/

Firefox版であればスマートフォンからも使用できます。

Tampermonkeyを起動し、ユーティリティ → URLからインポートで以下のURLを入力してください。

https://raw.githubusercontent.com/4STRA1/pommu-bookmarks/main/pommu-bookmarks.user.js

インストール画面が表示されたら「インストール」を選択してください。

また、js本体のプログラムコードをコピーして、新規ユーザースクリプトに貼り付けて保存することでもインストールできます。

https://raw.githubusercontent.com/4STRA1/pommu-bookmarks/main/pommu-bookmarks.user.js

機能

- 投稿をブックマーク
- ブックマークした投稿にタグを追加
- タグによる投稿の絞り込み
- 複数タグによるAND / OR検索
- 未分類の投稿を表示
- ブックマーク一覧から投稿を開く
- 投稿者プロフィールへの移動
- ブックマークデータの書き出し
- ブックマークデータの読み込み
- ブックマークデータを別の端末・ブラウザへ移行
- PC・スマートフォンに対応
- ブックマーク情報をブラウザ内に保存

使い方

DLsiteのPommuを開くと、投稿の「いいね」ボタンの右側にブックマークボタンが追加されます。

ブックマークボタンを押すと、投稿をブックマークできます。

初めてブックマークする場合は、タグを設定して保存できます。

すでにブックマークしている投稿では、同じボタンからタグの編集やブックマークの解除ができます。

ブックマーク一覧

Pommuのサイドメニューに追加される「ブックマーク」から、保存した投稿を一覧で確認できます。

一覧では以下の操作ができます。

- 投稿の閲覧
- 投稿者プロフィールへの移動
- タグの編集
- タグによる絞り込み
- AND / ORによる複数タグ検索
- ブックマークの追加・解除

タグ検索

タグは複数設定できます。

複数のタグを選択した場合は、

AND

選択したすべてのタグが付いている投稿を表示します。

OR

選択したタグのいずれかが付いている投稿を表示します。

「未分類」を選択すると、タグが付いていない投稿のみ表示できます。

データの保存

ブックマークデータはTampermonkeyの保存領域に保存されます。

Tampermonkeyが利用できない場合は、ブラウザのlocalStorageを使用します。

ブックマークデータは以下の「書き出し」ボタンからJSONファイルとして保存できます。

また、「読み込み」から保存したJSONファイルを読み込むことができます。

別の端末・ブラウザへの移行

ブックマークデータは自動的に他の端末やブラウザと同期されません。

別の端末やブラウザで使用する場合は、以下の手順で移行できます。

1. 現在使用している環境で「ブックマーク」を開く
2. 「書き出し」を選択
3. JSONファイルを保存
4. 新しい端末・ブラウザにTampermonkeyとこのスクリプトをインストール
5. 「ブックマーク」を開く
6. 「読み込み」を選択
7. 保存したJSONファイルを選択

これでブックマークやタグを移行できます。

データの自動同期について

現在、Google Driveなどの外部サービスを使用した自動同期には対応していません。

そのため、複数の端末で同じブックマークを使用する場合は、JSONファイルを使ってデータを移行してください。

通信について

このスクリプトは、Pommuが通常行っている投稿取得の通信を監視して、投稿のIDなどを取得します。

スクリプト自身がブックマーク取得のためにPommuのAPIへ追加のリクエストを送信する仕組みではありません。

注意事項

このスクリプトはDLsiteの公式機能ではありません。

サイト側の仕様変更などにより、正常に動作しなくなる場合があります。

ブックマークデータはブラウザ側に保存されるため、Tampermonkeyのデータを削除した場合などにブックマークが失われる可能性があります。

重要なブックマークデータは、定期的に「書き出し」からJSONファイルとしてバックアップすることをおすすめします。
